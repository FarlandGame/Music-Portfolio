## 制作の流れ

アイデア：Claude → 歌詞：ChatGPT → 音楽制作：Suno → 音声抽出：InShot → カバー制作：PhotoshopとAI。本人によると、両曲は自身のSoundCloudでも公開されています。

制作者クレジットは、企画、AIを活用した制作、ビジュアルディレクションを示します。人間による歌唱やAIを使わない作曲を主張するものではありません。受け取った音源とポスターは変更せずに保存しています。
